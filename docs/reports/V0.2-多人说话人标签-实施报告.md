## 补记（2026-11-10 晚：UI 适老化优化，用户指示）

用户提出三点：暂停时开始按钮不够大、老年机竖屏/小分辨率显示不全、黑底对老年人是否有利。变更：

1. **巨大开始按钮**：未聆听时（未开始/已停止/出错）显示全宽大按钮（小屏下 ≥76px 高），出错时文案“重新开始”；聆听时显示底部“停止字幕”。两处启停按钮不同时出现（避免重复困惑）。
2. **小屏/竖屏适配**：≤480px 宽或 ≤520px 高时控件紧凑排布；修复 `.subtitle-area` 缺 `min-height:0` 导致小屏控件被裁切的问题。
3. **底色可切换**：新增深色（默认）/浅色高对比切换，偏好存 localStorage。**记录偏差**：FR-03 原文“不在首版扩展多套主题”，本次按用户明确要求增加单一切换（非多套主题），影响仅为显示层。
4. **顺带修复既有缺陷**：`mic-block`/`btn-new` 的 HTML `hidden` 属性被 CSS `display:flex/block` 覆盖（“采音中”“有新字幕”未开始时也常显，M1 起即存在）——全局 `[hidden]{display:none!important}` 修复。
5. 验证：64 项 pytest 通过；真实浏览器 320×480 竖屏 DOM 检查（无横向溢出、控件完整可见、hidden 生效、主题切换生效）+ 截图人工复核。

黑底证据摘要（回答用户问题）：多数研究中老年人**主观上浅底黑字更易读、更偏好**（泰国 60–73 岁平板研究；Ergonomics 2025 认知得分浅色更高），生理上（瞳孔缩小、对比敏感度下降、眼内散射）深底更易视疲劳（ACM 2025）；但个体差异大，两极性各有受益人群（arXiv 2409.10841，134 人），且偏好≠表现。结论：黑底对老年人**无普遍正面作用**，暗环境客厅用深底可减少屏幕刺眼；以家人自选为准。
