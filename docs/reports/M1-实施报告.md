## 已验证通过

- 归并语义：修订覆盖、定稿冻结、乱序/空文本/重复容错、session 隔离（pytest + node 双端）
- 签名：HMAC-SHA1 黄金向量（openssl 独立计算）、参数排序、urlencode、voice_id 每次连接唯一
- 重试策略：1s/2s/5s 三次上限、鉴权/欠费类不重试、重试不重放旧音频、断开后新 voice_id/session_id
- 尾句：end→限时收尾，超时保留文字且不伪称定稿
- 访问控制：访问码校验、Cookie 下发、静态资源鉴权、WS 无码 4401 / 跨站 Origin 4403
- 用量：服务端硬配额（单次/每日）、超限正常结束并说明原因、`var/usage.json` 无内容元数据持久化、重启不清零、北京时间自然日重置、剩余额度不足一包拒绝开始
- 生命周期：重复 start 拒绝、单客户端占用（第二客户端明确提示 busy）、断开即清理、心跳空闲清理、协议错误不断连

## 已知缺陷与影响

1. 配额剩余不足 1 包（200ms）时开始会话立即被拒——有意收紧，避免“开始即停”（已入接口约定）。
2. 后端计账按浏览器上行音频时长（1:1 实时率下=上游音频时长）；重连间隙前端暂停发送，因此与腾讯侧计费口径可能有秒级差异——账单以供应商结算为准（需求 §8 口径）。
3. AGENTS.md §1 状态行更新被受保护文件写入拦截，尚未同步（当前状态以 README 与本报告为准）；待用户允许后更新。
4. 前端“上一句”按行滚动定位，长句换行场景下步进粒度较粗——不影响阅读主流程。
