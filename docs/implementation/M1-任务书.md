# M1 任务书（本轮阶段授权记录）

> 记录时间：2026-11-09。授权来源：用户本轮对话的阶段安排指令（正文如下，由实施协调者整理入档）。
> 基线：[MVP 需求文档 V0.2](../requirements/MVP需求文档_V0.2.md) 与 [AGENTS.md](../../AGENTS.md)。

## 用户指令（原文要点）

本轮调整阶段安排：允许在家庭方言验证尚未完成的情况下，推进 M1 实现，并同步准备 M2 局域网 Pad 试用条件。
目标是交付可在 Windows 运行、回家后能由 Android Pad 通过受信任 HTTPS 访问的实时字幕网页。
先完成核心界面、采音、真实腾讯云链路、启停清理、访问控制与用量限制，再提供局域网配置和试用说明。
家庭方言效果、实际 Pad 收音和阅读体验保留为待验收，不得宣称 M0/M2 已通过。
本轮不部署公网、不做声纹识别或其他扩展功能。遇到缺少凭据或设备时，继续完成独立工作并列明依赖。
