# M3 云端部署说明（asr.hao-rizon.com）

> 部署形态：腾讯云 Ubuntu（129.204.31.88，与 hao-rizon 同机）+ 单边缘 Caddy 自动 HTTPS
> + familyasr 非 root systemd 服务（回环 127.0.0.1:7020）。**服务器工作区永远等于某个
> git 提交**（镜像式发布），配置即代码，绝不在服务器上手改文件。
> 凭据（腾讯云三元组、访问码）只存服务器 `/srv/familyasr/.env`（不入库、不进聊天）。

## 1. 首次安装（已在 2026-11-09 执行，留档复现用）

```bash
# 服务器（以 ubuntu 登录，切勿 root 直接 clone）
sudo mkdir -p /srv/familyasr && sudo chown ubuntu:ubuntu /srv/familyasr
git clone ssh://git@github-familyasr/AaronOvO-LLL/familyasr.git /srv/familyasr
cd /srv/familyasr
python3 -m venv .venv
.venv/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
nano .env            # 按 .env.example 填：凭据、ACCESS_TOKEN、HOST=127.0.0.1、配额
sudo cp deploy/familyasr.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now familyasr
```

SSH 认证：服务器 `~/.ssh/config` 里 `Host github-familyasr → ssh.github.com:443`，
密钥 `~/.ssh/id_ed25519_familyasr`（只读部署密钥，注册在 GitHub 仓库 Deploy keys）。

边缘接入：`asr.hao-rizon.com` 站点块在 hao-rizon 仓库 `deploy/Caddyfile`
（软链为 /etc/caddy/Caddyfile），`reverse_proxy 127.0.0.1:7020`，WebSocket 自动升级。

## 3. 密钥 / 访问码更新

1. 改 `/srv/familyasr/.env` 对应行（`ASR_*` 或 `ACCESS_TOKEN`）；
2. `sudo systemctl restart familyasr`；
3. 本地 `.env` 同步更新（保持两端一致）。密钥不进 git、不进聊天、不进日志。

## 4. 版本发布与回滚

- 发布：本地 `git push` 后 `bash scripts/deploy.sh`；脚本在服务器执行
  `git fetch && git reset --hard origin/main`（镜像式，服务器树==提交）→ 依赖同步 →
  重启 → 健康检查。输出 `DEPLOY_OK <sha>` 为成功。
- 回滚：`ssh ubuntu@129.204.31.88 'cd /srv/familyasr && git reset --hard <好提交sha> && sudo systemctl restart familyasr'`。
- 边缘（Caddyfile）变更走 hao-rizon 仓库发布流，`caddy validate` 通过才 reload。

## 5. 安全边界

- 仅 Caddy 的 80/443 对外；应用只监听回环，7020 不开安全组。
- 全站 HTTPS/WSS（Let's Encrypt 自动证书）；页面与 WebSocket 均需家庭访问码
  （Cookie + 同源校验），服务端硬配额（默认每日 120 分钟、单次 120 分钟，北京
  时间自然日重置，`var/usage.json` 持久化，重启不清零）。
- 单客户端并发控制：同一时刻只允许一个识别会话。
- 日志只记会话元数据（状态/时长/错误码/用量），不含音频、识别文字、密钥；
  uvicorn 访问日志的查询串已脱敏（`?<redacted>`）。
- systemd 单元为非 root 运行，NoNewPrivileges/ProtectSystem 加固。

## 7. 故障排查

| 现象 | 处理 |
|---|---|
| 公网 502 | `systemctl status familyasr`；应用没起来看 `journalctl -u familyasr -n 50` |
| 页面 401 | URL 带 `?token=<ACCESS_TOKEN>`；访问码是否更新过 |
| WS 连上但无字幕 | `journalctl -u familyasr -f` 看 session 秒数是否增长；错误码 upstream_* 对照腾讯错误表 |
| 证书告警 | Caddy 自动续期；`sudo journalctl -u caddy -n 50` |
| 发布失败 | 看 deploy.sh 输出；服务器工作区必须干净（镜像式）；回滚见 §4 |
