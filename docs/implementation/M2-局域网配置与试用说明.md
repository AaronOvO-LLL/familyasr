# M2 局域网配置与 Pad 试用说明（条件准备，非验收）

> 目的：让 Android Pad 在家里的局域网上通过**受信任 HTTPS** 访问 Windows 上运行的字幕网页，
> 具备 M2 试用条件。**本文档不代表 M2 验收**——家庭方言效果、实际 Pad 收音与阅读体验
> 保留待验收（见 docs/reports/M1-实施报告.md）。
> 约束（需求 §7 Android/M2）：`getUserMedia` 要求安全上下文，`http://192.168.x.x` 不可用；
> 不关闭浏览器安全检查、不以忽略证书错误验收；本轮不部署公网。

## 0. 依赖清单（执行前需要齐备）

| 依赖 | 状态 | 获取方式 |
|---|---|---|
| mkcert（本地受信任证书工具） | 待安装 | `winget install FiloSottile.mkcert`（或 scoop/choco） |
| Windows 主机局域网 IP（如 192.168.x.x） | 运行时确认 | `ipconfig` 查看“无线局域网适配器 WLAN/以太网”的 IPv4 |
| Android Pad + Chrome/Edge | 家中实机 | 型号/系统/浏览器版本按需求 Q2 记录 |
| `ACCESS_TOKEN` 家庭访问码 | 已可配置 | 写入 `.env`（≥8 位随机串，勿入库） |
| 腾讯云真实链路凭据 | **未提供** | `ASR_APPID/ASR_SECRET_ID/ASR_SECRET_KEY` 填 `.env`（试用真实识别必需；mock 模式不需要） |

## 1. 原理（为什么要 mkcert）

Android 浏览器的麦克风 API 只在“安全上下文”（HTTPS + 受信任证书）下可用。
自签证书会触发“不安全”警告且 `getUserMedia` 可能被拒——需求明确禁止以忽略证书错误验收。
mkcert 生成由**本地 CA 签发**的证书；把这个 CA 装到 Pad 上作为信任凭据后，
浏览器视为受信任，地址栏无警告，麦克风正常申请。

```
Pad (Chrome) ──HTTPS/WSS(受信任证书)──> Windows 家语字幕屏 (FastAPI, 局域网 IP)
                                          │
                                          └──WSS(签名鉴权)──> 腾讯云实时 ASR V2
```

## 2. Windows 端配置

### 2.1 安装 mkcert 并生成证书（把 192.168.x.x 换成你的实际 IP）

```powershell
winget install FiloSottile.mkcert      # 一次性安装
mkcert -install                         # 把本地 CA 装入 Windows 信任库
mkcert 192.168.x.x home.local          # 生成证书：192.168.x.x+证书名目录下的 .pem/.key
```

生成的 `192.168.x.x+1.pem` / `192.168.x.x+1-key.pem` 移到本仓库外的私有目录
（仓库 .gitignore 已排除 *.pem/*.key；私钥不入库、不发聊天）。

### 2.2 配置 .env

```text
ASR_PROVIDER=tencent          # 真实链路需凭据齐备；无凭据可先 mock 演练流程
ACCESS_TOKEN=<12位以上随机串>
HOST=0.0.0.0                  # 允许局域网访问（仅限家庭私有网络）
PORT=7020
TLS_CERT_FILE=C:/path/to/192.168.x.x+1.pem
TLS_KEY_FILE=C:/path/to/192.168.x.x+1-key.pem
DAILY_LIMIT_SECONDS=1800      # 按需求 1.2 默认；试用额度勿随意放大
```

### 2.3 防火墙：仅对“专用网络”开放 7020

```powershell
New-NetFirewallRule -DisplayName "familyasr-lan" -Direction Inbound `
  -Protocol TCP -LocalPort 7020 -Profile Private -Action Allow
```

只选 `Private`（家庭网络配置文件）。**不要**选 Public，不要在路由器上做端口转发。

### 2.4 启动

```text
run.cmd                         # 或 .venv\Scripts\python.exe scripts\run_server.py
```

启动输出会打印 `https://0.0.0.0:7020/` 与访问码提示。保持窗口运行（Windows 关机后不可用，
云端独立使用属 M3 范围）。

## 3. Pad 端配置（一次性）

1. 把 mkcert 生成的根 CA 拷到 Pad：在 Windows 上运行 `mkcert -CAROOT` 打开目录，
   将 `rootCA.pem` 通过文件传输发到 Pad（本文件不是密钥，但仍走私人渠道）。
2. Pad：设置 → 安全/加密与凭据 → 安装证书 → CA 证书 → 选择 `rootCA.pem`（名称如 “mkcert …”）。
3. Chrome 打开 `https://192.168.x.x:7020/?token=<ACCESS_TOKEN>`（IP 换实际值）。
   - 地址栏应无“不安全”警告；首次会询问麦克风权限 → 选允许。
   - 建议添加到主屏幕，横屏使用。

## 4. 试用步骤（非验收，发现问题记录即可）

1. Pad 打开页面 → 点“开始字幕”→ 授权麦克风 → 状态变“正在聆听”（🎤 采音中）。
2. 普通话正常说话 → 临时句逐步出现、停顿后定稿；点“停止字幕”→ 3 秒内尾句收完，字幕保留。
3. 检查：字号 36/48/60/72、全屏、上翻回看不被抢位、“回到最新”、屏幕常亮、
   断网/关页后重新开始是否干净（无残留会话、无继续计费）。
4. 用量：页面右上显示“今日已用 X / Y 分钟”；试用后可用 `GET /health` 与服务日志核对会话清理。
5. 基础试用关闭电视；三种语言与混说分开试（结果记入 M0 结果记录表，不在本文档判定）。

## 5. 安全与收尾

- 试用只在家庭私有网络进行；不在公网、不共享访客 Wi-Fi、不做端口转发。
- 访问码仅家庭成员持有；怀疑泄漏就换一个（改 .env 重启即生效）。
- 试用结束停止服务（关窗口 / Ctrl+C）；长期不用时删除防火墙规则：
  `Remove-NetFirewallRule -DisplayName "familyasr-lan"`。
- 日志只含会话元数据（状态、时长、错误码），不含音频、识别文字与密钥；出现疑似泄漏立即停止并更换密钥。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| Pad 打开显示“不安全”或麦克风不弹权限 | CA 未装好或访问用了 http；重装 rootCA.pem、确认地址是 https:// |
| 显示 401 访问码页 | URL 带 `?token=`；或重新输入访问码 |
| “另一台设备正在使用” | 只允许一个识别会话；关掉电脑上的旧页面 |
| 显示“已达今日用量上限” | 服务端硬配额（默认 30 分钟/日），明天自动重置；试用配额调整见 .env |
| 收音断断续续 | 确认 Windows 防火墙只开 Private；路由器开启 AP 隔离时关闭之（Pad 与 PC 需互通） |
