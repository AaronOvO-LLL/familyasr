## 2. 标签返回语义（官方文档口径）

- 文档形状 `sentences`（SpeakerSentences）字段：`sentence / sentence_type / sentence_id / speaker_id / start_time / end_time`。
- **`speaker_id`：起始 `-1` 表示未产生准确的说话人信息；产生准确信息后该字段替换为正数指代具体角色。有效取值 `0–9`，最多分离 10 人。**
  - **`0` 是有效 ID**（任务书 B 明确要求不得把有效值 0 误判为空）。
- 实测抓包形状（2026-11-09，见 skill 参考与 test_transcript.py）：`result{slice_type,index,voice_text_str,...,speaker_info}`，`speaker_info` 在无说话人引擎时为 `null`，有说话人信息时为 `{"speaker_id": N}`。两种形状解析器均覆盖。
- 修订行为（文档"产生准确说话人信息后…替换"）：同一句允许 `-1 → 0..9` 的标签**后补**；文档未承诺定稿后的标签修订，本项目**定稿即冻结文字与标签**，不为标签解冻。
- 词级信息：实测回包含 `word_list`，但其字段结构未核验；**不使用词级标签**。句级 `speaker_info` 是唯一标签来源；缺失/无法可靠归属 → 未知（`-1`，显示"说话人待确认"），不把整句强归某人。

## 3. 权限、计费与用量

| 项 | 结论 | 来源 |
|---|---|---|
| 权限 | 与现有实时 V2 相同（AppID/SecretId/SecretKey），无需新开通 | 接口文档 |
| 计费 | `16k_zh_en_speaker_2.0` 属"大模型 2.0 版"引擎，仅适用于大模型 2.0 计费方案（后付费 1.0 元/小时口径与现用引擎一致） | 接口文档 + [计费概述（在线版）](https://cloud.tencent.cn/document/product/1093/35686)（页面更新 2026-10-29） |
| 待核实 | 计费框架表另有"实时说话人分离"子产品行（无免费额度、不支持预付费、后付费日结）；与 speaker 引擎**是否叠加计费，页面文本无法确定**。真实短测后以账单核实，如有独立计费立即报告用户 | 同上 |
| 用量约束 | 不变：每日 120 分钟 / 单次 120 分钟硬配额，密钥仅后端环境，保持不动 | 任务书 §4.A.4 |

**结论：能力支持，无需新付费开通即可切换模型；费用以小额真实短测账单复核。**

## 4. 对比基线配置

| 配置 | 模型 | 标签 |
|---|---|---|
| 基线（现网默认） | `16k_zh_en_2.0` | 无（speaker_info 恒 null） |
| 候选（V0.2） | `16k_zh_en_speaker_2.0` | 有（0–9 / -1） |

对比测试保持相近设备、距离、语言与话轮任务（任务书 §5）；不为对比录制家庭对话、不建并发收费会话。

## 5. 可逆配置（任务书 §4.B：两者效果不得混淆）

| 操作 | 效果 | 性质 |
|---|---|---|
| `SPEAKER_LABELS=off` | **仅隐藏标签显示**，模型与识别文字不变（speaker 引擎照常识别） | 显示开关 |
| `ASR_ENGINE_MODEL_TYPE=16k_zh_en_2.0` | **切回无标签基线模型**，恢复既有无标签模式的文字质量/延迟基线 | 模型切换 |
